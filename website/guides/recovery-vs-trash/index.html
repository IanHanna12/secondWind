Recovery

Finder Trash vs local Recovery

Both destinations keep a cleanup action reversible for a time. They are not the same thing, so the final review asks you to choose deliberately.

Finder Trash

Finder Trash uses macOS’s ordinary deletion flow. The item remains available until the Trash is emptied. Choose it when you want the standard Mac behavior and do not need Second Wind to manage the item afterward.

Local Recovery

Recovery stores the payload locally with a manifest describing its original location, size, rule context, category, and any known application association. It stays available until you explicitly restore it or permanently delete it.

What Recovery adds

  • Restore to the original location when there is no conflict.
  • Explicit choices when something already exists: cancel, restore beside it, choose another destination, or replace only after separate confirmation.
  • Integrity checks that can mark a missing or damaged item as non-restorable while keeping the state visible.
  • Local activity and audit context linked to the cleanup operation.

Choose before execution

Opening a review does not move files. The final plan shows the selected entries and destination before you confirm. If the plan is not understandable, go back—there is no benefit in continuing a cleanup you cannot explain.

Permanent deletion remains separate

Neither route is an unlimited undo system. Emptying Finder Trash is a macOS action. Permanent deletion from Recovery requires a separate explicit confirmation. Keep current backups for important data regardless of the destination you choose.

Common questions

Does Recovery immediately increase free space?

No. Recovery moves the payload into storage managed locally by Second Wind, so it remains on the same Mac and continues to use disk space. Its purpose is controlled restoration, not immediate capacity recovery. Finder Trash also continues using space until the Trash is emptied.

What happens if the original location already exists?

Second Wind does not silently replace it. Restore offers an explicit choice to cancel, restore beside the existing item, choose another destination, or replace only after separate destructive confirmation. If integrity cannot be established, restore remains disabled while the damaged state stays visible.

Good default for uncertainty

If the reviewed item is large and you may need it again, choose Recovery. If you understand the item and prefer normal macOS deletion behavior, choose Finder Trash.
